# Contributing

Contributions must preserve the clean-room and public-only boundary in `PROVENANCE.md`.

1. Open an issue describing the behavior to change.
2. Keep identifiers generic and dependencies public.
3. Run `make check` for static checks.
4. Run `make verify` for any runtime or documentation contract change.
5. Update `CHANGELOG.md` and relevant documentation.

Never submit credentials, keys, certificates, private URLs, internal source, copied configuration, or proprietary assets. By contributing, you agree that your contribution is licensed under Apache-2.0.
